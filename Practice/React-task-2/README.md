# Horizon Courts

A simple tennis-themed landing page section built with React and CSS.

## Features

- Navigation bar
- Hero section with call-to-action button
- Tennis-themed background image
- Social media links
- Hover effects and transitions
- CSS variables for styling

## Tech Stack

- React
- CSS
- Vite

## Purpose

This project was created as a frontend practice task to improve React component structure and CSS layout skills.
