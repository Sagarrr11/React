# React Routing & Context Practice

A small React practice application built to practice routing, hooks, API fetching, and Context API.

---

## 🚀 Features

- React Router DOM
- Nested Routing
- Dynamic Routing
- `useParams`
- `useNavigate`
- `Link`
- `Outlet`
- `useEffect`
- Axios API fetching
- Context API
- `useContext`
- Context Provider
- `children` prop

---

## 🛠️ Tech Stack

- React
- JavaScript
- React Router DOM
- Axios
- Tailwind CSS
- Vite

---

## 📚 What I Practiced

This project was built while learning React to understand how routing, API fetching, hooks, and Context API work together in a small application.

---

```bash
npm install
