# User Form & Recent Users

A simple React application that allows users to enter their name and email, submit the form, and dynamically display submitted users in a recent-user list.

## 🚀 Features

- Add user's name and email
- Controlled form inputs
- Form submission handling
- Dynamically display users
- Clear inputs after submission
- User cards styled with Tailwind CSS

## 🛠️ Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite

## 🧠 Concepts Practiced

- `useState`
- Controlled Components
- `onChange`
- `onSubmit`
- `preventDefault()`
- Array Spread Operator
- `.map()`
- `key` prop
- State management
